# Budget Tracker Analysis

Python, Pandas aur Matplotlib ka use karke banaya gaya ek simple budget tracker.

## Features
- Income aur expense ka data store karna
- Category-wise kharche ka analysis
- Total income, total expense aur balance nikalna
- Charts se spending ko visualize karna

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## How to Run
1. Notebook `Budget_Tracker.ipynb` ko Google Colab mein kholein (notebook ke upar "Open in Colab" badge par click karein).
2. Saare cells ko upar se neeche run karein.
